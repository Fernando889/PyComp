# Text Processing Services[]{#stringservices} {#textservices}

The modules described in this chapter provide a wide range of string manipulation operations and other text processing services.

The `codecs`{.interpreted-text role="mod"} module described under `binaryservices`{.interpreted-text role="ref"} is also highly relevant to text processing. In addition, see the documentation for Python\'s built-in string type in `textseq`{.interpreted-text role="ref"}.
