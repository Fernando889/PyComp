# Data Types {#datatypes}

The modules described in this chapter provide a variety of specialized data types such as dates and times, fixed-type arrays, heap queues, double-ended queues, and enumerations.

Python also provides some built-in data types, in particular, `dict`{.interpreted-text role="class"}, `list`{.interpreted-text role="class"}, `set`{.interpreted-text role="class"} and `frozenset`{.interpreted-text role="class"}, and `tuple`{.interpreted-text role="class"}. The `str`{.interpreted-text role="class"} class is used to hold Unicode strings, and the `bytes`{.interpreted-text role="class"} and `bytearray`{.interpreted-text role="class"} classes are used to hold binary data.
