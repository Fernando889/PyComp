# Data Compression and Archiving {#archiving}

The modules described in this chapter support data compression with the zlib, gzip, bzip2, lzma, and zstd algorithms, and the creation of ZIP- and tar-format archives. See also `archiving-operations`{.interpreted-text role="ref"} provided by the `shutil`{.interpreted-text role="mod"} module.
