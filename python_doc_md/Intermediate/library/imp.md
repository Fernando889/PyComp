# `!imp`{.interpreted-text role="mod"} \-\-- Access the import internals

::: {.module synopsis="Removed in 3.12." deprecated=""}
imp
:::

::: deprecated-removed
3.4 3.12
:::

This module is no longer part of the Python standard library. It was `removed in Python 3.12 <whatsnew312-removed-imp>`{.interpreted-text role="ref"} after being deprecated in Python 3.4.

The `removal notice <whatsnew312-removed-imp>`{.interpreted-text role="ref"} includes guidance for migrating code from `!imp`{.interpreted-text role="mod"} to `importlib`{.interpreted-text role="mod"}.

The last version of Python that provided the `!imp`{.interpreted-text role="mod"} module was [Python 3.11](https://docs.python.org/3.11/library/imp.html).
