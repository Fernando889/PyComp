# `!crypt`{.interpreted-text role="mod"} \-\-- Function to check Unix passwords

::: {.module synopsis="Removed in 3.13." deprecated=""}
crypt
:::

::: deprecated-removed
3.11 3.13
:::

This module is no longer part of the Python standard library. It was `removed in Python 3.13 <whatsnew313-pep594>`{.interpreted-text role="ref"} after being deprecated in Python 3.11. The removal was decided in `594`{.interpreted-text role="pep"}.

Applications can use the `hashlib`{.interpreted-text role="mod"} module from the standard library. Other possible replacements are third-party libraries from PyPI: `legacycrypt`{.interpreted-text role="pypi"}, `bcrypt`{.interpreted-text role="pypi"}, or `argon2-cffi`{.interpreted-text role="pypi"}. These are not supported or maintained by the Python core team.

The last version of Python that provided the `!crypt`{.interpreted-text role="mod"} module was [Python 3.12](https://docs.python.org/3.12/library/crypt.html).
