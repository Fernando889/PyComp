# Numeric and Mathematical Modules {#numeric}

The modules described in this chapter provide numeric and math-related functions and data types. The `numbers`{.interpreted-text role="mod"} module defines an abstract hierarchy of numeric types. The `math`{.interpreted-text role="mod"} and `cmath`{.interpreted-text role="mod"} modules contain various mathematical functions for floating-point and complex numbers. The `decimal`{.interpreted-text role="mod"} module supports exact representations of decimal numbers, using arbitrary precision arithmetic.
