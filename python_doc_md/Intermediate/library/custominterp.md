# Custom Python Interpreters {#custominterp}

The modules described in this chapter allow writing interfaces similar to Python\'s interactive interpreter. If you want a Python interpreter that supports some special feature in addition to the Python language, you should look at the `code`{.interpreted-text role="mod"} module. (The `codeop`{.interpreted-text role="mod"} module is lower-level, used to support compiling a possibly incomplete chunk of Python code.)

The full list of modules described in this chapter is:

:::
