# `!asynchat`{.interpreted-text role="mod"} \-\-- Asynchronous socket command/response handler

::: {.module synopsis="Removed in 3.12." deprecated=""}
asynchat
:::

::: deprecated-removed
3.6 3.12
:::

This module is no longer part of the Python standard library. It was `removed in Python 3.12 <whatsnew312-removed>`{.interpreted-text role="ref"} after being deprecated in Python 3.6. The removal was decided in `594`{.interpreted-text role="pep"}.

Applications should use the `asyncio`{.interpreted-text role="mod"} module instead.

The last version of Python that provided the `!asynchat`{.interpreted-text role="mod"} module was [Python 3.11](https://docs.python.org/3.11/library/asynchat.html).
