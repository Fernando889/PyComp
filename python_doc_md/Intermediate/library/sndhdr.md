# `!sndhdr`{.interpreted-text role="mod"} \-\-- Determine type of sound file

::: {.module synopsis="Removed in 3.13." deprecated=""}
sndhdr
:::

::: deprecated-removed
3.11 3.13
:::

This module is no longer part of the Python standard library. It was `removed in Python 3.13 <whatsnew313-pep594>`{.interpreted-text role="ref"} after being deprecated in Python 3.11. The removal was decided in `594`{.interpreted-text role="pep"}.

Possible replacements are third-party modules from PyPI: `filetype`{.interpreted-text role="pypi"}, `puremagic`{.interpreted-text role="pypi"}, or `python-magic`{.interpreted-text role="pypi"}. These are not supported or maintained by the Python core team.

The last version of Python that provided the `!sndhdr`{.interpreted-text role="mod"} module was [Python 3.12](https://docs.python.org/3.12/library/sndhdr.html).
