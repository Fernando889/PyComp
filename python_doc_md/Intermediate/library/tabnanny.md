# `!tabnanny`{.interpreted-text role="mod"} \-\-- Detection of ambiguous indentation

::: {.module synopsis="Tool for detecting white space related problems in Python
source files in a directory tree."}
tabnanny
:::

**Source code:** `Lib/tabnanny.py`{.interpreted-text role="source"}

------------------------------------------------------------------------

For the time being this module is intended to be called as a script. However it is possible to import it into an IDE and use the function `check`{.interpreted-text role="func"} described below.

:::: note
::: title
Note
:::

The API provided by this module is likely to change in future releases; such changes may not be backward compatible.
::::

::: function
check(file_or_dir)

If *file_or_dir* is a directory and not a symbolic link, then recursively descend the directory tree named by *file_or_dir*, checking all `.py`{.interpreted-text role="file"} files along the way. If *file_or_dir* is an ordinary Python source file, it is checked for whitespace related problems. The diagnostic messages are written to standard output using the `print`{.interpreted-text role="func"} function.
:::

::: data
verbose

Flag indicating whether to print verbose messages. This is incremented by the `-v` option if called as a script.
:::

::: data
filename_only

Flag indicating whether to print only the filenames of files containing whitespace related problems. This is set to true by the `-q` option if called as a script.
:::

::: exception
NannyNag

Raised by `process_tokens`{.interpreted-text role="func"} if detecting an ambiguous indent. Captured and handled in `check`{.interpreted-text role="func"}.
:::

::: function
process_tokens(tokens)

This function is used by `check`{.interpreted-text role="func"} to process tokens generated by the `tokenize`{.interpreted-text role="mod"} module.
:::

::: seealso

Module `tokenize`{.interpreted-text role="mod"}

:   Lexical scanner for Python source code.
:::
