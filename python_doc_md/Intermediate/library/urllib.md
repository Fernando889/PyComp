# `!urllib`{.interpreted-text role="mod"} \-\-- URL handling modules

::: module
urllib
:::

**Source code:** `Lib/urllib/`{.interpreted-text role="source"}

------------------------------------------------------------------------

`urllib` is a package that collects several modules for working with URLs:

- `urllib.request`{.interpreted-text role="mod"} for opening and reading URLs
- `urllib.error`{.interpreted-text role="mod"} containing the exceptions raised by `urllib.request`{.interpreted-text role="mod"}
- `urllib.parse`{.interpreted-text role="mod"} for parsing URLs
- `urllib.robotparser`{.interpreted-text role="mod"} for parsing `robots.txt` files
