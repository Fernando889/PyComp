# `!smtpd`{.interpreted-text role="mod"} \-\-- SMTP Server

::: {.module synopsis="Removed in 3.12." deprecated=""}
smtpd
:::

::: deprecated-removed
3.6 3.12
:::

This module is no longer part of the Python standard library. It was `removed in Python 3.12 <whatsnew312-removed>`{.interpreted-text role="ref"} after being deprecated in Python 3.6. The removal was decided in `594`{.interpreted-text role="pep"}.

A possible replacement is the third-party `aiosmtpd`{.interpreted-text role="pypi"} library. This library is not maintained or supported by the Python core team.

The last version of Python that provided the `!smtpd`{.interpreted-text role="mod"} module was [Python 3.11](https://docs.python.org/3.11/library/smtpd.html).
