# `!distutils`{.interpreted-text role="mod"} \-\-- Building and installing Python modules

::: {.module synopsis="Removed in 3.12." deprecated=""}
distutils
:::

::: deprecated-removed
3.10 3.12
:::

This module is no longer part of the Python standard library. It was `removed in Python 3.12 <whatsnew312-removed-distutils>`{.interpreted-text role="ref"} after being deprecated in Python 3.10. The removal was decided in `632`{.interpreted-text role="pep"}, which has [migration advice](https://peps.python.org/pep-0632/#migration-advice).

The last version of Python that provided the `!distutils`{.interpreted-text role="mod"} module was [Python 3.11](https://docs.python.org/3.11/library/distutils.html).
