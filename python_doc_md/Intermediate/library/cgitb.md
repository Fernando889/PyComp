# `!cgitb`{.interpreted-text role="mod"} \-\-- Traceback manager for CGI scripts

::: {.module synopsis="Removed in 3.13." deprecated=""}
cgitb
:::

::: deprecated-removed
3.11 3.13
:::

This module is no longer part of the Python standard library. It was `removed in Python 3.13 <whatsnew313-pep594>`{.interpreted-text role="ref"} after being deprecated in Python 3.11. The removal was decided in `594`{.interpreted-text role="pep"}.

A fork of the module on PyPI can now be used instead: `legacy-cgi`{.interpreted-text role="pypi"}. This is a copy of the cgi module, no longer maintained or supported by the core Python team.

The last version of Python that provided the `!cgitb`{.interpreted-text role="mod"} module was [Python 3.12](https://docs.python.org/3.12/library/cgitb.html).
